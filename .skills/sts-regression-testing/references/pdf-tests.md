# PDF Tests

For BH01/BH02/BH03-style fixtures assert:

- A4 page size and expected page count.
- Borehole/project labels and required intervals.
- Every sample, SPT, subordinate note, defect and zone.
- Correct complete/refusal/partial SPT notation.
- Soil-to-rock continuation and termination.
- No clipped text, broken glyph, split number or omitted observation.

Render all pages at 144 dpi or higher and inspect them. Text extraction alone is insufficient.
