# Pagination

- A4 portrait unless the approved template says otherwise.
- Preserve fixed header, track and footer geometry across sheets.
- Soil depth windows use the existing measured 10 m contract unless a template version changes explicitly.
- Rock windows follow core/run content and measured renderer constants.
- Never split a number, clip a description, or orphan a boundary label.
- Page count and `Sheet X of Y` must agree after all content is laid out.
- A continuation note never replaces the next sheet's actual content.
