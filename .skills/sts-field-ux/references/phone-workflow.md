# Phone Workflow

Persistent header: borehole ID, current depth, save/sync and validation count.

Main: current material, current run, last boundary and recent observations.

Primary command: Add observation. Short actions may use a bottom sheet; complex soil/SPT/defect records use a full-screen editor. Bottom navigation: Project, Borehole, Capture, Review, More.

No critical horizontal scrolling. Interval summaries may be compact, but all structured values remain reachable in the editor. Minimum target 44 px.
