# Description Order

Use structured values and the repository generator. Preserve manual amendments.

Soil working order:

1. Origin/fill qualifier where applicable.
2. Primary material and secondary fraction.
3. Plasticity or grain-size descriptors.
4. Colour.
5. Consistency or relative density.
6. Moisture.
7. Structure, inclusions and subordinate depth notes.

Rock working order:

1. Rock type and secondary lithology.
2. Colour and grain/fabric/bedding.
3. Weathering.
4. Strength.
5. Alteration and notes.

Do not silently replace a manually amended description. Show structured, manually amended and out-of-sync states. Regeneration is an explicit user command and must be auditable.
