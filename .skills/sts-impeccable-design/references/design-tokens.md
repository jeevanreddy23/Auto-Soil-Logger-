# Design Tokens

Spacing: 4, 8, 12, 16, 24, 32, 48 px.

Radii: 4-6 px compact controls, 6-8 px inputs/buttons, 8 px panels; pills only for true statuses/tags.

Roles:

- STS green: brand, active navigation, confirmed state and primary command.
- Graphite: table headers and navigation structure.
- Amber: warning; red: blocker/destructive; blue: active information/focus.
- White and cool neutral grey: working surfaces.

Typography: Segoe UI/Arial working family, fixed sizes, zero letter spacing, tabular numerals for measurements.
