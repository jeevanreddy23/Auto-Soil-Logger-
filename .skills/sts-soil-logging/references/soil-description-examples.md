# Soil Description Examples

Normal structured example:

`Silty CLAY: medium plasticity, pale grey-brown, stiff, moist.`

Fill example:

`FILL: Silty SAND: red-grey, fine to medium grained, trace subangular gravel and low plasticity clay.`

Depth-specific notes remain separate:

- `1.80 m: becoming pale red-brown`
- `2.15 m: occasional ironstone gravel`
- `2.60-2.80 m: gravel content increasing`

Ambiguous combinations stay editable and require review. Do not force a vocabulary value that changes the logger's intended meaning.
