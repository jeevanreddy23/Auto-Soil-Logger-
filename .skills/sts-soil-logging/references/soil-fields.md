# Soil Fields

Common: from, to, origin, primary material, secondary material, colour, plasticity or grain size, consistency or relative density, moisture, classification, description.

Advanced: grading, proportions, particle size/shape/angularity, structure, cementation, mottling, staining, roots, organic matter, inclusions, fill constituents, boundary type, confidence, geological interpretation.

Description metadata: generated basis, manual-edit flag/state, amendment timestamp/by when available.

Subordinate note: durable ID, point depth or from/to, text, source and audit metadata.

Store numbers as numeric values where the current schema permits; display metres consistently without duplicating units in every field.
