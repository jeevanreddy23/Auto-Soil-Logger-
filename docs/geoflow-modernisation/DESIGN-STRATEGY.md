# Design Strategy

## Product Scene

An engineering geologist uses a phone or tablet beside a rig in direct sunlight, then a reviewer opens the same borehole on desktop to reconcile depth tracks and issue a log. The interface therefore uses a light working surface, high-contrast graphite structure, restrained STS green, stable dimensions and no decorative motion.

## First Slice

- Desktop/tablet: retain the efficient grid and sticky headers; add a compact selected-row description state and actionable validation.
- Phone: present interval summaries and one full-screen structured editor; do not expose a clipped 1900 px table as the primary workflow.
- Keep one dominant command per action strip.
- Use semantic blocker/warning/valid states with text and symbols.
- Preserve current depth and borehole context while editing.

## Impeccable Sequence

The soil workspace is evaluated through shape, critique, distill, layout, typeset, adapt, harden, audit and polish. Findings are limited to the approved slice; unrelated screens are not redesigned.

## Anti-Patterns

No gradients, glass, nested cards, decorative charts, large welcome content, rounded icon tiles, excessive pills, or motion that does not communicate state.
